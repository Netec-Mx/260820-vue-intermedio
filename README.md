# Vue Intermedio

Consolidar y aplicar conceptos intermedios y avanzados de Vue.js, abarcando reactividad, composición de componentes, estado, routing y arquitecturas para aplicaciones escalables y robustas.

## Estructura

- `CapituloXX/README.md`: guía de laboratorio por capítulo.

## Lista de laboratorios

### Capítulo 1

- [4 Practica: diagnóstico y optimización de renders en una SPA](Capitulo01/README.md#4-practica-diagnóstico-y-optimización-de-renders-en-una-spa)
  - Descripción: Diagnosticar problemas de actualización y rendimiento en una SPA y aplicar técnicas de optimización de renders basadas en el modelo de reactividad y el ciclo de vida de Vue.
  - Duración estimada: 24 min

### Capítulo 2

- [4 Practica: refactorizar componentes a Composition API y crear composables](Capitulo02/README.md#4-practica-refactorizar-componentes-a-composition-api-y-crear-composables)
  - Descripción: Refactorizar componentes existentes mediante Composition API y crear composables para estructurar lógica reutilizable y comparar estrategias de composición.
  - Duración estimada: 30 min

### Capítulo 3

- [4 Practica: implementar flujo de autenticación con rutas protegidas y carga dinámica](Capitulo03/README.md#4-practica-implementar-flujo-de-autenticación-con-rutas-protegidas-y-carga-dinámica)
  - Descripción: Implementar un flujo de autenticación con rutas protegidas, navigation guards, control de acceso y carga dinámica, considerando el impacto del enrutamiento sobre el rendimiento.
  - Duración estimada: 46 min

### Capítulo 4

- [4 Practica: diseñar y aplicar una arquitectura de stores para una aplicación compleja](Capitulo04/README.md#4-practica-diseñar-y-aplicar-una-arquitectura-de-stores-para-una-aplicación-compleja)
  - Descripción: Diseñar y aplicar una arquitectura de stores con Pinia para una aplicación compleja, considerando modularidad, persistencia, composición de stores y manejo de side-effects.
  - Duración estimada: 46 min

### Capítulo 5

- [4 Practica: implementar clientes REST y GraphQL con manejo de cache y errores](Capitulo05/README.md#4-practica-implementar-clientes-rest-y-graphql-con-manejo-de-cache-y-errores)
  - Descripción: Implementar clientes REST y GraphQL incorporando estrategias de cache, normalización y manejo centralizado de errores para lograr comunicaciones fiables y manejables.
  - Duración estimada: 46 min

### Capítulo 6

- [4 Practica: aplicar optimizaciones y medir mejoras en una SPA real](Capitulo06/README.md#4-practica-aplicar-optimizaciones-y-medir-mejoras-en-una-spa-real)
  - Descripción: Aplicar técnicas de optimización sobre una SPA real y medir las mejoras obtenidas mediante profiling, métricas de rendimiento, code-splitting, lazy loading y técnicas avanzadas de renderizado.
  - Duración estimada: 46 min

### Capítulo 7

- [4 Practica: crear una estrategia de pruebas para una aplicación Vue](Capitulo07/README.md#4-practica-crear-una-estrategia-de-pruebas-para-una-aplicación-vue)
  - Descripción: Crear una estrategia de pruebas para una aplicación Vue que integre pruebas unitarias, pruebas de componentes, pruebas E2E, debugging y mantenimiento para garantizar la calidad del código.
  - Duración estimada: 46 min

### Capítulo 8

- [4 Practica final: diseñar y desplegar una aplicación escalable con pipeline automatizado](Capitulo08/README.md#4-practica-final-diseñar-y-desplegar-una-aplicación-escalable-con-pipeline-automatizado)
  - Descripción: Diseñar y desplegar una aplicación Vue escalable con arquitectura modular y un pipeline automatizado, incorporando estrategias de CI/CD, entornos, observabilidad y rollback.
  - Duración estimada: 43 min
